# Image credits

Every picture in this folder is an original illustration drawn by
`backend/scripts/generate_site_assets.py` (gradients and simple shapes, saved as WebP at several
widths, with `manifest.json` listing them). None is a photograph, none is licensed from a third
party, and none shows a real person. They stand in for the photography a real practice would
commission: replace them by running the script with your own artwork, or by dropping real files
with the same names and widths into this folder and updating `manifest.json`.

The four forms in `frontend/public/forms/` are also generated by that script.
